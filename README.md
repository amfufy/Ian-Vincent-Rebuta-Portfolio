# Ian Vincent Rebuta — Landing Page & Website Portfolio

Portfolio of landing pages and websites by Ian Vincent Rebuta (Pvblicly).

## Editing
Everything is set in the `<script>` near the bottom of `index.html`:

- `ME` — name, role, email, booking link, Pvblicly link, tools.
- `PROJECTS` — each project's title, description, highlights and live link.

## Adding real screenshots
1. Upload screenshots into the `shots/` folder (e.g. `shots/happyhobby.png`).
2. In `PROJECTS`, add `image: "shots/happyhobby.png"` to that project.
The screenshot replaces the illustrated preview. Use a 16:10 shape (e.g. 1600×1000) so it fits the browser frame.

## Hosting
Served with GitHub Pages from the `main` branch root.
